# fastfind
'find' wrapper for Unix based systems.. The goal of this project is to make the syntax easier and faster to type.

Note that this is a beginner project, so things may not work as intended.

### Installation:
```bash
1. git clone https://github.com/jeanyyyyy/fastfind
2. cd fastfind
3. bash install.sh
```

Done!
